Definitions: Defect rate = fix PRs linked to an issue with a defect label (bug, defect, regression, incident, production-bug, or type: bug) ÷ merged PRs. This is an explicit-label proxy; it does not prove preventability or distinguish a review-escaped bug from a missed requirement. Revert rate = PRs titled Revert ... or typed subjects such as fix: revert ..., plus Git commits containing This reverts commit; duplicate evidence and temporary changes reverted within the same merged PR are excluded. These are GitHub signals—not DORA Change Failure Rate, which requires production deployment and rollback/hotfix data.

Weekly, by merge week of the earlier PR · a week appears once its 30-day window has closed

Escaped-fix rate: of the PRs merged in a week, the share that a later PR had to fix within 30 days. A later PR becomes a candidate when it, or the issue it closes, names the earlier PR (#N or a link), uses causal wording (broke, regression, caused by, introduced in), or reverts it. A candidate counts only after a judge confirmed that it fixes a mistake the earlier PR made (defect_from_original), not a planned follow-up. Severe = a fix judged high severity. Caveats: this is a lower bound, because fixes that never mention the earlier PR are missed (an offline replay found more than a third of real fixes only through shared files). Verdicts are AI judgments unless judged_by in fix-judgments.csv names a person, and anyone can correct a row there. Unjudged candidates are shown so you can see how complete a week is.
